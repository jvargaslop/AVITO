# 🥑 AVITO — Sistema Digital de Pedidos Interactivos

**AVITO** es una aplicación web interactiva diseñada para optimizar la toma y recepción de pedidos de *bowls* personalizados en tiempo real. Este proyecto aplica principios de **Diseño de Servicios (*Service Design*)** para mejorar la comunicación entre la experiencia del cliente (interfaz de selección) y el flujo operativo interno (pantalla de cocina/recepción).

---

### 🎯 Problema que resuelve
El proceso tradicional de personalización de alimentos en mesa o caja puede generar cuellos de botella y errores en la comandas. **AVITO** digitaliza el proceso permitiendo al cliente componer su plato paso a paso con retroalimentación clara, reduciendo tiempos de espera y eliminando fallas en la preparación.

---

### ✨ Características Principales
- 🥣 **Personalizador de Bowls:** Interfaz dinámica e interactiva para seleccionar bases, proteínas, aderezos y toppings.
- 🔄 **Sincronización en Tiempo Real:** Pantalla para recepción y seguimiento de pedidos conectada a la base de datos.
- 📱 **Diseño Claramente Estructurado:** Flujo de usuario limpio y guiado para una navegación intuitiva sin fricciones.
- ⚡ **Integración Backend:** Conexión persistente con Supabase para la administración eficiente de datos y estados de pedido.

---

### 🛠️ Tecnologías y Metodología
- **Frontend:** HTML5, CSS3, JavaScript.
- **Base de Datos & Backend:** Supabase (BaaS / PostgreSQL).
- **Enfoque:** Diseño de Servicios (*Service Design*) y Experiencia de Usuario (UX/UI).
- **Metodología de Desarrollo:** Desarrollo e iteración asistidos por Inteligencia Artificial (Claude AI).
